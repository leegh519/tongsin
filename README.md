# 지방직·서울시 9급 통신이론 기출 문제은행

참고 프로젝트: https://github.com/leegh519/elec
기존 문제풀이 UI를 통신이론 전용으로 구성했습니다. HTML/CSS/JavaScript 정적 웹앱으로 GitHub Pages와 로컬 파일 실행을 지원합니다. Sites를 사용하지 않습니다.

## 실행

`index.html`을 브라우저로 열거나, 폴더에서 `python -m http.server 8765` 실행 후 http://localhost:8765 에 접속합니다.

- 시험구분·연도·장·절 필터(필터 내 OR, 필터 간 AND)
- 한 문제씩 / 여러 문제 모아풀기, 무작위 / 연도순
- 채점, 이전·다음, 즐겨찾기, 오답·미풀이 필터
- 브라우저별 풀이 기록 저장 및 JSON 가져오기·내보내기
- 원문 PNG 저장, 이미지 복사, `review.html` 이미지·정답·분류 검수

## 수록 현황

34회차에서 선별한 **594문항**, 전부 **9급**입니다. 7급은 수록하지 않습니다.

- 지방직 통신이론: 2009~2011, 2022~2026 — 160문항
- 서울시 통신이론: 2014~2021 — 160문항
- 국가직 9급 무선공학개론: 2009~2026 원본 360문항 중 통신이론 공통범위 **274문항** 선별
- **2010 서울시는 원문 미확보로 아직 수록하지 않았습니다.**
- 공식 정답표 적용 409문항, 공식 대조 전 잠정 정답 185문항. 잠정 정답은 채점 시 별도로 표시합니다.
- 문항번호·파일·원본·분류 연결 검사를 완료했고 대표 이미지를 시각 확인했습니다. 전 문항 육안 검수는 미완료입니다.

### 국가직 선별 기준

국가직 9급의 원래 과목명은 **무선공학개론**입니다. 이를 통신이론으로 바꾸어 표기하지 않고 문제 카드와 검수 목록에 원과목을 표시합니다.

제공 목차와 지방직·서울시 기출에 대응하는 표본화·부호화·변복조·잡음·채널용량·확산대역·이동통신·OFDM·MIMO·무선랜·기본 전파/위성/거리계산 등을 선별했습니다. 전송선로 임피던스·급전/정합·안테나 상세·레이더 방정식/성능·항법/GPS·전리층 등 무선공학 전용 심화 내용 86문항은 제외했습니다.

전체 360문항의 포함/제외 결정과 대표 절은 `review/national-overlap-audit.json`에 있습니다. `6-12 주요 무선통신 기술`은 기존 지방직의 기본 전파·위성·반파장 안테나·레이더 왕복시간 기출과 같은 수준까지 포함합니다. 특정 문제의 풀이가 어렵다는 이유만으로 제외하지는 않았습니다.

## 분류

이론책의 9개 단원은 유지하고 73개 절을 **43개 학습 주제**로 통합했습니다. 화면에서 Chapter 번호와 1-1 같은 세부목차 번호를 모두 제거했습니다.

- 신호 분류·기본 파형, 푸리에 급수·변환, 시스템 특성·임펄스 응답을 각각 통합
- FM·PM·비교를 각변조로 통합
- 랜덤 변수·확률분포, 랜덤 과정·정상성, 전력·에너지 스펙트럼을 각각 통합
- 디지털 변조 종류·성능 비교 및 확산 통신의 개요·방식·응용을 통합
- 이동통신은 세대별 기술, 셀·주파수 재사용, 구성·채널로 묶고 기타 무선 기술과 구분
- 정보량·엔트로피, 이산 통신로·상호 정보량, TCP/IP·전송제어 등을 각각 통합

정합 필터와 등화기, 파형 부호화와 보코딩처럼 구분이 필요한 주제는 유지합니다. 목차에 직접 대응하지 않는 회로·논리회로 6문항은 `목차 외 · 분류 검토`로 보존합니다.

원래 목차는 `data/book_taxonomy.json`, 문제별 원래 절은 `classification.bookPrimaryTopic`, 통합 대응표는 `review/topic-merge-map.json`에 남겼습니다. `실전예상문제`는 기출의 개념 분류가 아니므로 별도 주제로 추가하지 않았습니다.

## GitHub Pages 배포

1. 통신이론용 새 GitHub 저장소를 만듭니다. 원본 `leegh519/elec`에 덮어쓰지 않습니다.
2. 이 폴더의 내용을 새 저장소 `main`에 업로드합니다(숨김 파일 `.github`와 `.nojekyll` 포함).
3. 저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 설정합니다.
4. Actions의 `Deploy GitHub Pages`를 실행하거나 `main`에 푸시합니다.

`.github/workflows/pages.yml`이 포함되어 있습니다. 상대 경로를 사용하므로 프로젝트 하위 경로에서도 실행됩니다. 저장소: https://github.com/leegh519/tongsin · GitHub Pages: https://leegh519.github.io/tongsin/

## 데이터 재생성

Python 3.10 이상에서 `python -m pip install -r tools/requirements.txt`로 의존성을 설치합니다.

```
python tools/build_bank.py
python tools/build_contact_sheets.py
python tools/validate_bank.py
```

원본 `sources/*.pdf` 및 수록 정답용 `sources/local-*.html`을 보존해야 합니다. 분류는 `data/classifications.json`, 확정·잠정 정답 기록은 `data/answer_keys.json`을 우선 적용합니다. 국가직은 분류 파일에 포함된 ID만 생성하므로 제외 문항이 재수록되지 않습니다. 새 시험은 원문·급수·책형·최종 정답을 확인하고 분류를 추가한 후 반영합니다. 이미지 자르기 재생성 시 검수 상태는 다시 확인해야 합니다.


## 제본 테스트 PDF

`print/tongsin_sample_4p.pdf`: A4, 단원 표지 1쪽과 문제 3쪽(12문항), 총 4쪽입니다. 목차 순으로 정렬하고 한 쪽을 왼쪽 위·아래, 오른쪽 위·아래 순서(`1 3 / 2 4`)로 읽도록 배치했습니다. 문항 위의 새 번호와 출처, 쪽 아래의 정답을 표시하며 원래 문제 번호는 가렸습니다.

재생성: `python tools/build_print_pdf.py --output print/tongsin_sample_4p.pdf` (Windows 바탕체 사용)
