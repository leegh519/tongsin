# 서울시 2018 통신이론 A형 14번 복수정답 반영

사용자가 2026-11-21 대화에서 최종정답 확정 후 ①(001)·②(000) 복수정답이 인정되었다고 알려주었다. 이를 채점에 반영했다.

기존 보관 파일 `official-answers/2018-서울시-정답.pdf`의 통신이론 A형 행에는 ①만 수록되어 있다. 이번 작업에서 복수정답이 적힌 최종 공고 원문은 확보하지 못했다. 따라서 최종 공고 원문까지 재대조한 것으로 표시하지 않고, `cross-checked` 및 사용자 제공 정보라는 출처를 남긴다.

독립 검산: D=1, B=01, C=001, A=000인 코드와 D=1, B=01, C=000, A=001인 코드 모두 접두부호이다. 두 경우 평균길이도 0.4×1+0.3×2+(0.2+0.1)×3=1.9로 같다. A와 C를 연결한 가지의 0·1을 교환해도 허프만 트리와 코드 길이는 변하지 않는다.

기존 대표값 `choice: 1`을 호환성 때문에 유지하고, 실제 채점·화면·PDF 정답 출력은 `choices: [1, 2]`를 사용한다.
