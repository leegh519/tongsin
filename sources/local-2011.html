통신이론

5.
CDMA(code division multiple access) 방식의 이동통신에 대한 설명으로 옳지 않은 것은?
통신이론
  1. ①채널 구분은 직교 부호와 의사잡음 부호의 적용을 통해 이루어진다.
  2. ②기지국과 단말기간의 거리와 전파환경 특성에 따른 전력제어가 필요하다.
  3. ③여러 사용자가 데이터를 전송하는 시간슬롯을 다르게 한다.
  4. ④인접 기지국의 사용자 부하가 적을수록 용량이 증가한다.

6.
가산 백색 가우시안 잡음이 존재하는 채널을 통하여 정보를 전송할 때 용량은 섀넌-하틀리(Shannon-Hartley) 이론이 적용된다고 알려졌다. 이에 대한 설명으로 옳지 않은 것은?
통신이론
  1. ①전송 대역폭이 증가하면 단위 시간당 전송할 수 있는 최대 정보량도 증가한다.
  2. ②채널 잡음이 증가하면 단위 시간당 전송할 수 있는 최대 정보량은 감소한다.
  3. ③신호대 잡음비(signal-to-noise ratio)가 증가하면 단위 시간당 전송할 수 있는 최대 정보량이 증가한다.
  4. ④섀넌-하틀리 이론은 오류 확률의 한계를 정하는 것이다.

8.

통신이론

  3. ③곱셈기의 출력신호의 위상은 각각 3π​, 6π​이다.
  4. ④입력신호들의 주파수 스펙트럼은 수학적으로 임펄스 함수를 이용하여 표현할 수 있다.

12.
OFDMA(orthogonal frequency division multiple access)에 대한 설명으로 옳은 것은?

  2. ②전송신호에 특정 부호를 곱하여 스펙트럼을 확산시킨다.
  3. ③주어진 통신 대역을 작은 부반송파 대역으로 나누어 사용자에게 할당한다.
  4. ④BASK 변조방식과 결합될 때 최적 수신 성능을 나타낸다.

16.
정합필터(matched filter)에 대한 설명으로 옳은 것은?
통신이론
  1. ①이진신호 검출에서 상관기(correlator)는 정합필터와 같은 기능을 수행할 수 있다.
  2. ②다중 경로로 수신된 신호에서 신호 대 잡음비(signal-to-noise ratio)를 최적화하기 위한 장치이다.
  3. ③노치(Notch) 필터는 정합필터의 하나이다.
  4. ④전송되는 디지털 신호 종류의 개수가 많을 때 수신기 구조를 간단하게 한다.

17.
푸리에 변환(Fourier transform)의 성질에 대한 설명으로 옳은 것은?
통신이론
  1. ①시간영역에서 신호의 시간 천이는 주파수영역에서 선형 위상 천이로 나타난다.
  2. ②모든 복소수 신호의 스펙트럼은 대칭으로 나타난다.
  3. ③시간영역에서 신호에 실수 지수함수를 곱하면 주파수 영역에서 주파수 천이된 스펙트럼으로 나타난다.
  4. ④시간영역에서 펄스신호의 펄스폭 감소는 주파수 영역에서 저주파 성분을 강화한다.

20.
네트워크 통신 장치인 리피터(repeater)에 대한 설명으로 옳은 것은?
통신이론
  1. ①디지털 전송에서는 리피터를 거치면서 잡음이 누적 증폭되는 효과가 발생할 수 있다.
  2. ②전송로의 감쇄와 잡음으로 손상된 원래 데이터를 재생하여 수신측으로 전송하는 장치이다.
  3. ③네트워크 회선에서 지나가는 신호를 감시하는 근거리 통신망 장치이다.
  4. ④패킷 데이터의 경로를 효과적으로 결정하기 위한 기능을 가져야 한다.
