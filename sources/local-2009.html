7.
(n, k) 블록 부호(block code)에 대한 설명으로 옳지 않은 것은?
통신이론
  1. ①총 2n개의 가능한 부호어(codeword) 중 2k개의 유효한 부호어가 사용된다.
  2. ②패리티(parity) 비트 수는 (n−k)개이다.
  3. ③부호율(code rate)은 nk​이다.
  4. ④부호율이 21​일 때, 전송 대역폭은 부호화하기 전보다 21​배로 줄어든다.

8.
정보이론과 부호화에 대한 설명으로 옳지 않은 것은?
통신이론
  1. ①정보원의 모든 심볼이 동등한 확률로 발생할 때 엔트로피 함수는 최소값을 갖는다.
  2. ②정보원 부호화 방법에서 허프만(Huffman) 부호화는 엔트로피에 근접한 평균 부호 길이를 갖는다.
  3. ③잡음이 있는 채널에서 데이터 전송률이 채널용량보다 작으면 임의의 작은 오류확률로 신호의 전송이 가능하다.
  4. ④단일 패리티 검사 부호는 정보 시퀀스에 단일 패리티 심볼을 더함으로써 형성될 수 있으며, 이 부호는 단일 오류를 검출할 수 있다.

9.
국제표준기구인 ISO에서 규정한 OSI(Open System Interconnection) 7계층에서 각 계층에 대한 설명으로 옳지 않은 것은?
통신이론
  1. ①데이터 링크 계층은 두 시스템 간의 데이터 전송을 위해 링크를 활성화하고 관리하기 위한 기계적, 전기적, 기능적, 절차적 특성 등을 정의한다.
  2. ②세션 계층은 프로세스간 연결을 확립하고 유지하며 동기화 한다.
  3. ③전송 계층은 TCP/UDP와 관련된 계층으로 오류 복구, 흐름 제어 기능을 담당한다.
  4. ④네트워크 계층은 상위 계층에 연결하는 데 필요한 데이터 전송과 경로 선택 기능을 제공하고, 라우팅 프로토콜을 사용하여 최적의 경로를 선택한다.

10.
스펙트럼 확산(spread spectrum) 통신 시스템에 대한 설명으로 옳지 않은 것은?
통신이론
  1. ①메시지 신호의 대역폭에 비해 상당히 넓은 전송 대역폭을 갖는다.
  2. ②메시지 신호와 상관이 큰 부호열에 의해 대역이 확산되는 시스템이다.
  3. ③송신 측에서 대역 확산에 사용된 부호열을 사용하여 수신 측에서 역확산이 이루어진다.
  4. ④다중경로 페이딩(multipath fading)에 의한 왜곡이나 간섭에 강하다.

통신이론

  3. ③기존의 바코드와는 달리 RFID는 데이터의 읽기와 쓰기가 가능하다.
  4. ④능동 태그는 수동 태그보다 인식 거리가 길다.

17.
디지털 통신의 기본적인 성능 측정 단위인 Eb​/N0​에 대한 설명으로 옳지 않은 것은?
통신이론
  1. ①Eb​는 신호전력과 비트 전송률의 곱이다.
  2. ②N0​는 잡음전력을 채널대역폭으로 나눈 값이다.
  3. ③Eb​는 신호전력의 크기에 비례한다.
  4. ④N0​는 잡음전력의 크기에 비례한다.

18.
통신시스템에 대한 설명으로 옳지 않은 것은?
통신이론
  1. ①데이터 전송률은 채널의 주파수 대역폭에 비례한다.
  2. ②회선을 구성하는 방식은 점대점 방식과 멀티포인트 방식이 있는데, 점대점 방식은 보안성이 좋으며 개인 사설회선에 적합하다.
  3. ③신호의 전송모드는 동기식과 비동기식이 있는데, 동기식은 전체 데이터를 한 문자씩 나누어서 전송한다.
  4. ④패킷교환에서는 전송되는 메시지를 작은 단위의 데이터블록으로 나누어서 전송하는 방식을 사용하며, 이 작은 데이터블록을 패킷이라고 한다.

19.
단일모드와 다중모드 광섬유에 대한 비교 설명으로 옳은 것은?
통신이론
  1. ①다중모드 광섬유는 단일모드에 비해 정보전송 용량이 크다.
  2. ②다중모드 광섬유의 코어 직경은 단일모드에 비해 작다.
  3. ③단일모드 광섬유의 접속은 다중모드에 비해 쉽다.
  4. ④단일모드 광섬유는 다중모드에 비해 장거리 전송에 유리하다.
